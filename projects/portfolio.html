Multi-Asset Portfolio Optimization

Portfolio Management • Modern Portfolio Theory

Developed and optimised a diversified multi-asset investment portfolio using Modern Portfolio Theory (MPT). The project analysed expected returns, volatility, correlations and portfolio optimisation to build an efficient portfolio across equities, fixed income, real estate, commodities and alternative investments.

Domain Portfolio Management
Tools Microsoft Excel
Methodology Modern Portfolio Theory (MPT)
Year 2025

Project Snapshot

Objective

Construct and optimise a diversified multi-asset portfolio using Modern Portfolio Theory by analysing expected returns, volatility, covariance and correlations across multiple asset classes.

Portfolio Strategy

Build a globally diversified portfolio comprising equities, government and corporate bonds, inflation-protected securities, REITs, commodities, gold and alternative assets to improve risk-adjusted performance through diversification.

Key Findings

Demonstrated how combining assets with imperfect correlations can reduce portfolio risk while maintaining attractive expected returns, resulting in more efficient portfolio allocations.

01

Asset Universe

The portfolio was constructed using a diversified set of asset classes, including global equities, fixed income securities, real estate, commodities and alternative investments. Rather than relying on a single market, the portfolio combines assets with different economic drivers to improve diversification.

The selected assets include SPY (US Equities), VGK (European Equities), VWO (Emerging Markets), IEF (US Treasuries), LQD (Investment Grade Corporate Bonds), TIP (Inflation-Protected Securities), VNQ (REITs), GLD (Gold), DBC (Broad Commodities) and Bitcoin in selected scenarios.

02

Portfolio Construction

The portfolio was constructed using the principles of Modern Portfolio Theory (MPT). Historical return data was used to estimate expected returns, volatility and the covariance between assets, providing the foundation for portfolio optimisation.

By combining assets with different risk and return characteristics, the optimisation process identified allocations that maximise expected return for a given level of risk. The analysis highlights how diversification, rather than concentrating investments in a single asset class, contributes to a more efficient portfolio.

03

Risk & Return Analysis

The portfolio was evaluated using expected returns, volatility, correlation and covariance metrics to understand the trade-off between risk and return. These measures provided the quantitative foundation for comparing different portfolio allocations.

The analysis showed that assets exhibited varying levels of return and risk, with correlations ranging from low to high across asset classes. Incorporating assets with lower correlations improved diversification and reduced overall portfolio volatility while maintaining competitive expected returns.

04

Efficient Frontier & Optimisation

Portfolio optimisation was performed using Excel Solver to identify asset allocations that maximise expected return for different levels of portfolio risk. The optimisation was based on Modern Portfolio Theory, using expected returns together with the covariance matrix while ensuring that portfolio weights satisfied the required constraints.

Multiple efficient portfolios were generated to form the Efficient Frontier, illustrating the set of optimal portfolios that offer the highest expected return for a given level of risk. This analysis demonstrates how optimisation techniques can support more informed investment decisions and improve risk-adjusted portfolio construction.

05

Scenario Analysis

Multiple optimisation scenarios were evaluated to understand how different assumptions affect portfolio performance. These included constraints such as prohibiting short selling, changes in market volatility and variations in the investment universe.

The comparison showed how portfolio constraints and changing market assumptions altered the shape of the Efficient Frontier and the resulting optimal portfolios. Analysing these scenarios demonstrated the importance of stress testing and sensitivity analysis when constructing robust investment strategies.
